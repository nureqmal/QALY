# QALY One Centre — v3

Professional business suite for Qaly. Zero AI dependency. Zero cost.

## Modules
| Module | Description |
|--------|-------------|
| Dashboard | Date header, KPIs, recent orders, upcoming events, system activity log |
| Sales Tracker | Google Form live pull + Shopee/manual orders with net profit tracking |
| Analytics | Revenue trend, product performance, channel breakdown |
| Inventory & Costing | Raw materials, stock levels, product costing, reorder alerts |
| Upcoming Events | Bazaars, exhibitions, campus events with countdown reminders |
| Team Hub | Meeting notes + private personal notes per team member |

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy (Streamlit Cloud — free)
1. Push to GitHub
2. share.streamlit.io → New app → select repo → app.py
3. Share URL with team

## Connect Google Form orders
1. Open your Google Sheets (form responses)
2. File → Share → Publish to web → CSV → Publish
3. Paste URL in Sales Tracker → Google Form Orders tab
